# Сбор сведений о недвижимости из ЕГРН

В `addresses.xlsx` на первом листе без заголовков укажите номер лицевого счёта (ЛС) в столбце A, адрес — в столбце B. Номера с ведущими нулями храните как текст. Пустые строки и повторы пары «номер ЛС — адрес» пропускаются. По каждому адресу выполняется один поиск за запуск, а результат записывается для каждого ЛС в очереди по этому адресу.

```sh
uv sync
uv run playwright install chromium
uv run python main.py
```

В открывшемся окне Chromium войдите в Личный кабинет Росреестра вручную, вернитесь в [сервис поиска объектов](https://lk.rosreestr.ru/eservices/real-estate-objects-online) и нажмите Enter в терминале. Программа не хранит данные сессии, не решает CAPTCHA и не отправляет запросы как гость.

Оставьте тип поиска «Поиск по адресу и кадастровому номеру» и не выбирайте вид объекта. Программа заполняет только адрес, открывает первый результат и сохраняет форму собственности и PNG серого блока «Сведения об объекте» в `screenshots/`. Между поисками выдерживается пауза в пять секунд.

Задержка перед снимком карточки — 0,5 секунды. Её можно изменить в `SCREENSHOT_DELAY_SECONDS` в `search.py`.

В `result.xlsx` на листе `Результаты` пять столбцов: `Номер ЛС`, `Адрес`, `Успешен ли поиск`, `Форма собственности`, `Название файла скриншота`. Результат сохраняется после каждого адреса. При подтверждённой пустой выдаче записывается `FALSE`, а две последние ячейки остаются пустыми. Повторный запуск пропускает пары «номер ЛС — адрес» с `TRUE` и обновляет строки с `FALSE` на месте. Запускайте только один экземпляр программы для одной книги.

Если остался `result.xlsx` старого формата (без номера ЛС), переименуйте его перед запуском. Программа не перезаписывает книгу с прежними заголовками.

После входа в кабинете терминал показывает прогресс по очереди текущего запуска. Счётчик увеличивается после записи результата в Excel, в том числе при пустой выдаче. Адрес, по которому все указанные ЛС уже имеют `TRUE`, в очередь не входит.

При потере сессии, появлении CAPTCHA или сбое программа останавливается, сохраняя уже записанные результаты. Код выхода: `0` — штатное завершение (в том числе при пустой выдаче), `1` — ошибка, `130` — Ctrl+C.

После каждого изменения Python-кода запускайте WPS из корня проекта:

```sh
uv run flake8 .
```

Автономная проверка без обращения к Росреестру:

```sh
uv run python -m unittest discover -s tests -p 'test_lookup.py'
```
