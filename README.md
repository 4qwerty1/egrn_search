# Сбор сведений о недвижимости из ЕГРН

Все рабочие файлы находятся в `data/`. В `data/addresses.xlsx` на первом листе без заголовков укажите номер лицевого счёта (ЛС) в столбце A, адрес — в столбце B. Номера с ведущими нулями храните как текст. Пустые строки и повторы пары «номер ЛС — адрес» пропускаются. Результат поиска записывается для каждого ЛС в очереди по этому адресу.

Команды запускайте из корня проекта:

```sh
uv sync
uv run playwright install chromium
uv run python -m egrn
```

Имена файлов и листа результатов, размер области Chromium, паузы, тайм-ауты и число попыток поиска настраиваются в [`egrn/config.py`](egrn/config.py). Паузы задаются в секундах, тайм-ауты и интервал проверки карточки — в миллисекундах. Изменения вступают в силу при следующем запуске. Ниже описаны значения по умолчанию.
Если меняете имя листа, переименуйте его и в существующей книге результатов.

При обновлении со старой раскладки сначала сохраните копию `addresses.xlsx`: раньше книга отслеживалась Git. Перед первым запуском по новой схеме перенесите её, существующий `result.xlsx`, `screenshots/` и `error_detail` (если есть) из корня в `data/`. Без прежней книги результатов программа не узнает, какие пары уже обработаны.

В открывшемся окне Chromium войдите в Личный кабинет Росреестра вручную, вернитесь в [сервис поиска объектов](https://lk.rosreestr.ru/eservices/real-estate-objects-online) и нажмите Enter в терминале. Программа не хранит данные сессии, не решает CAPTCHA и не отправляет запросы как гость.

Оставьте тип поиска «Поиск по адресу и кадастровому номеру» и не выбирайте вид объекта. Программа заполняет только адрес и пробует результаты по порядку, включая следующие страницы выдачи. С первой открывшейся карточки сохраняются форма собственности и PNG серого блока «Сведения об объекте» в `screenshots/`. Между поисками выдерживается пауза в пять секунд.

Если карточка не появилась в течение секунды после исчезновения индикатора загрузки (или после нажатия, если индикатор не появился), программа пробует следующий результат. После появления карточки программа ждёт 0,5 секунды. Затем она сверяет кадастровый номер из раздела «Общая информация» с номером строки выдачи, читает форму собственности и делает снимок. Ранее присвоенные номера в сверке не участвуют. Программа также ждёт одну секунду после ввода адреса, после появления результатов или сообщения об их отсутствии и после скриншота, в том числе последнего.

Имя PNG берётся из адреса: запрещённые в Linux или Windows символы удаляются, слишком длинные имена обрезаются. Если имя уже занято, перед `.png` добавляется `_` и пять шестнадцатеричных цифр (например, `_00000`). Существующие скриншоты не перезаписываются; в Excel записывается фактическое имя файла.

В `result.xlsx` на листе `Результаты` пять столбцов: `Номер ЛС`, `Адрес`, `Успешен ли поиск`, `Форма собственности`, `Название файла скриншота`. Результат сохраняется после каждого адреса. При пустой выдаче статус — `Адрес не найден`; если ни один результат не открылся — `Не получилось открыть карточку объекта`. В этих случаях две последние ячейки пусты. Если поле «Форма собственности» отсутствует или дублируется, в статус записывается причина, форма собственности остаётся пустой, а скриншот карточки сохраняется. Во всех этих случаях поиск продолжается со следующим адресом.

При успешном поиске в графу `Успешен ли поиск` записывается `Да`. Повторный запуск пропускает все пары «номер ЛС — адрес», уже записанные в `result.xlsx`: успешные, с сообщением об ошибке или с прежним `TRUE`/`FALSE`. Чтобы повторить поиск для пары, удалите её строку из книги результатов. Запускайте только один экземпляр программы для одной книги.

Если остался `result.xlsx` старого формата (без номера ЛС), переименуйте его перед запуском. Программа не перезаписывает книгу с прежними заголовками.

После входа в кабинете терминал показывает прогресс по очереди текущего запуска. Счётчик увеличивается после записи результата в Excel, в том числе если выдача пуста, карточки не открылись или в карточке есть ошибка поля «Форма собственности». Если результаты для всех указанных ЛС по адресу уже сохранены, адрес не входит в очередь.

Если за 30 секунд не появилась новая выдача, программа заново открывает страницу поиска в той же сессии, снова вводит тот же адрес и запускает поиск. При появлении выдачи она обрабатывает результаты как обычно. После третьего тайм-аута ожидания выдачи программа останавливается с ошибкой, не записывая этот адрес в Excel.

При потере сессии, появлении CAPTCHA, тайм-ауте индикатора загрузки или другом необработанном сбое программа останавливается, сохраняя уже записанные результаты. Код выхода: `0` — штатное завершение, в том числе при сохранении перечисленных выше статусов; `1` — необработанная ошибка; `130` — Ctrl+C.

Если при открытой странице перехвачено исключение (в том числе ошибка поля «Форма собственности»), программа сохраняет снимок всей страницы Chromium, включая область прокрутки, в `error_detail` (PNG без расширения рядом с `result.xlsx`). Каждый новый снимок заменяет предыдущий. Пустая выдача и отсутствие открывшихся карточек сами по себе снимок ошибки не создают.

После каждого изменения Python-кода запускайте WPS из корня проекта:

```sh
uv run flake8 .
```

Автономная проверка без обращения к Росреестру:

```sh
uv run python -m unittest discover -s tests -p 'test_lookup.py'
```
