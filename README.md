# Сбор сведений о недвижимости из ЕГРН

## Задача

Перебрать список адресов и для каждого адреса:

- найти объект недвижимости на сайте росреестра
- определить его форму собственности
- сделать скриншот сведений об объекте недвижимости с сайта росреестра
- заполнить таблицу результатов: адрес, успешен ли поиск, форма собственности, название файла скриншота

Алгоритм поиска объекта недвижимости в росреестре:

- зайти в [сервис](https://lk.rosreestr.ru/eservices/real-estate-objects-online) росреестра по поиску объекта недвижимости
- заполнить форму поиска:
  - Тип поиска: "Поиск по адресу и кадастровому номеру"
  - Вид объект: оставить пустым
  - Введите символы с картинки:
    - скачать изображение
    - загрузить в локальное API по анализу
    - заполнить поле текстом, которое отдаст API
  - Адрес или кадастровой номер: ввести адрес из списка
- нажать кнопку "Найти"
- выбрать первый из результатов
- прочитать значение поля "Форма собственности"
- сделать и сохранить скриншот сведений об объекте (серый прямоугольник)
