# Сбор сведений о недвижимости из ЕГРН

В `addresses.txt` укажите по одному адресу на строку (UTF-8). Программа пропускает пустые строки и повторы, сохраняя порядок адресов.

```sh
uv sync
uv run playwright install chromium
uv run python main.py
```

В открывшемся окне Chromium войдите в Личный кабинет Росреестра вручную, вернитесь в [сервис поиска объектов](https://lk.rosreestr.ru/eservices/real-estate-objects-online) и нажмите Enter в терминале. Программа не хранит данные сессии, не решает CAPTCHA и не отправляет запросы как гость.

Оставьте тип поиска «Поиск по адресу и кадастровому номеру» и не выбирайте вид объекта. Программа заполняет только адрес, открывает первый результат и сохраняет форму собственности и PNG серого блока «Сведения об объекте» в `screenshots/`. Между поисками выдерживается пауза в пять секунд.

Задержка перед снимком карточки — 0,5 секунды. Её можно изменить в `SCREENSHOT_DELAY_SECONDS` в `main.py`.

В `result.xlsx` на листе `Результаты` четыре столбца: `Адрес`, `Успешен ли поиск`, `Форма собственности`, `Название файла скриншота`. Результат сохраняется после каждого адреса. При подтверждённой пустой выдаче записывается `FALSE`, а две последние ячейки остаются пустыми. Повторный запуск пропускает строки с `TRUE` и обновляет строки с `FALSE` на месте. Запускайте только один экземпляр программы для одной книги.

После входа в кабинете терминал показывает прогресс по очереди текущего запуска. Счётчик увеличивается после записи результата в Excel, в том числе при пустой выдаче. Уже успешные адреса не входят в очередь.

При потере сессии, появлении CAPTCHA или сбое программа останавливается, сохраняя уже записанные результаты. Код выхода: `0` — штатное завершение (в том числе при пустой выдаче), `1` — ошибка, `130` — Ctrl+C.

Автономная проверка без обращения к Росреестру:

```sh
uv run python -m unittest discover -s tests -p 'test_lookup.py'
```
