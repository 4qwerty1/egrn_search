# Сбор сведений о недвижимости из ЕГРН

В `addresses.xlsx` на первом листе без заголовков укажите номер лицевого счёта (ЛС) в столбце A, адрес — в столбце B. Номера с ведущими нулями храните как текст. Пустые строки и повторы пары «номер ЛС — адрес» пропускаются. По каждому адресу выполняется один поиск за запуск, а результат записывается для каждого ЛС в очереди по этому адресу.

```sh
uv sync
uv run playwright install chromium
uv run python main.py
```

В открывшемся окне Chromium войдите в Личный кабинет Росреестра вручную, вернитесь в [сервис поиска объектов](https://lk.rosreestr.ru/eservices/real-estate-objects-online) и нажмите Enter в терминале. Программа не хранит данные сессии, не решает CAPTCHA и не отправляет запросы как гость.

Оставьте тип поиска «Поиск по адресу и кадастровому номеру» и не выбирайте вид объекта. Программа заполняет только адрес, открывает первый результат и сохраняет форму собственности и PNG серого блока «Сведения об объекте» в `screenshots/`. Между поисками выдерживается пауза в пять секунд.

Программа ждёт одну секунду после ввода адреса, после появления результатов или сообщения об их отсутствии и после скриншота, в том числе последнего. Пауза перед снимком карточки — 0,5 секунды (`SCREENSHOT_DELAY_SECONDS` в `search.py`).

Имя PNG берётся из адреса: запрещённые в Linux или Windows символы удаляются, слишком длинные имена обрезаются. Если имя уже занято, перед `.png` добавляется `_` и пять шестнадцатеричных цифр (например, `_00000`). Существующие скриншоты не перезаписываются; в Excel записывается фактическое имя файла.

В `result.xlsx` на листе `Результаты` пять столбцов: `Номер ЛС`, `Адрес`, `Успешен ли поиск`, `Форма собственности`, `Название файла скриншота`. Результат сохраняется после каждого адреса. При пустой выдаче статус — `Адрес не найден`, две последние ячейки пусты. Если поле «Форма собственности» отсутствует или дублируется, в статус записывается причина, форма собственности остаётся пустой, а скриншот карточки сохраняется. В обоих случаях поиск продолжается со следующим адресом.

При успешном поиске в графу `Успешен ли поиск` записывается `Да`. Повторный запуск пропускает все пары «номер ЛС — адрес», уже записанные в `result.xlsx`: успешные, с сообщением об ошибке или с прежним `TRUE`/`FALSE`. Чтобы повторить поиск для пары, удалите её строку из книги результатов. Запускайте только один экземпляр программы для одной книги.

Если остался `result.xlsx` старого формата (без номера ЛС), переименуйте его перед запуском. Программа не перезаписывает книгу с прежними заголовками.

После входа в кабинете терминал показывает прогресс по очереди текущего запуска. Счётчик увеличивается после записи результата в Excel, в том числе при пустой выдаче или ошибке поля «Форма собственности». Если результаты для всех указанных ЛС по адресу уже сохранены, адрес не входит в очередь.

При потере сессии, появлении CAPTCHA или другом необработанном сбое программа останавливается, сохраняя уже записанные результаты. Код выхода: `0` — штатное завершение (в том числе при пустой выдаче или ошибке поля «Форма собственности»), `1` — необработанная ошибка, `130` — Ctrl+C.

После каждого изменения Python-кода запускайте WPS из корня проекта:

```sh
uv run flake8 .
```

Автономная проверка без обращения к Росреестру:

```sh
uv run python -m unittest discover -s tests -p 'test_lookup.py'
```
